# Data and code availability

Analysis code and the processed datasets included in this repository are available at https://github.com/runzhihuang2022/Huang_2026_Fib_K14.

The `Figure1–Figure6`, `FigureS1–FigureS7` and `TableS1` directories provide figure-oriented entry points. Canonical processed inputs, count matrices and result tables are retained under `modules/`; file hashes and transformations are recorded under `provenance/`.

Raw sequencing reads, original large H5AD/RDS objects, raw ATAC fragments/Arrow files and whole-slide microscopy images are not deposited in this Git repository. `data/external_assets.csv` lists the registered large-data assets, hashes when available, and current access status. Blank public-accession fields indicate that no verified public accession was supplied. Missing experimental source tables and metadata remain identified in the panel and evidence-gap registers.

Human-derived release tables use module-specific public identifiers. The original private linkage files are excluded. This repository provides the processed resources listed in its manifests and does not claim that every underlying raw dataset is publicly accessible through GitHub.
