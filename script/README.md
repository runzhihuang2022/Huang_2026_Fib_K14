# Analysis and figure entry points

- `../run_reproduce.py`: the six tested reproduction groups.
- `run_figure.py --figure Figure1`: stage and execute the supporting tasks assigned to a figure.
- `../modules/core/scripts/`: processed-data/count-model analyses.
- `../modules/mechanism/scripts/`: complementary R count models, GSEA and patient-level analyses.
- `../modules/figure_s7/scripts/`: exact V12 S7 data-driven build.
- `../analysis_archive/`: original atlas, trajectory, CellOracle, chromatin, communication, cross-species and imaging code, with historical stages kept explicit.

Original Python/R/IPython/Groovy implementations are retained; no R Markdown analysis is invented for a workflow that was not originally R Markdown.
