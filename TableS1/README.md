# Table S1

`Table_S1.xlsx` is the complete 11-worksheet public derivative of the submission workbook. It includes figure assay aliases, human/animal cohort metadata, annotation and marker resources, QC summaries, gene sets and mapping parameters. Original private specimen links were replaced by module-specific public identifiers; the private crosswalk is not uploaded.

CSV exports are included for machine-readable reuse. Re-export and audit with `python run_reproduce.py --modules core`; the first core task checks all 11 worksheets. These assay mappings do not establish independent-animal identities where those were not supplied.
