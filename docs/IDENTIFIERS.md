# Identifier policy

Release data use module-specific pseudonyms. Numerical values, group labels and sample grouping are retained. The original-to-release map is kept outside this repository. The Table S1, KC/SAC source and mechanism analyses used different historical patient codings; equal suffixes across these namespaces must not be interpreted as a verified patient identity. A patient crosswalk between those source systems remains unresolved. This package contains a public derivative of Table S1, not the unchanged submission workbook.

Original data remain intact. Workstation paths and user profile directories are replaced in release copies. Path replacement does not validate historical scripts; those scripts remain archived/not run until their external inputs and configurations are supplied.
