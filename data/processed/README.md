# Processed data

Canonical data used by executable analyses are stored in:

- `../../modules/core/data/processed/`: bulk counts, retained atlas observations, KC/SAC counts, trajectories, histology, ATAC evidence, spatial proteins and Table S1.
- `../../modules/figure_s7/source_data/`: current S7 plot inputs and preserved H&E fields.
- `../../modules/mechanism/data/` and `../../modules/mechanism/tables/`: two count matrices, gene annotation and complete mechanism result tables.

Each Figure folder contains a source-data manifest linking to these canonical locations. Large original matrices, raw sequencing and full-slide images are listed in `../external_assets.csv`; verified public accessions have not yet been supplied for every external item.
